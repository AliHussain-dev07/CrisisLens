CrisisLens

A student mental-health web app (Version 1.0 prototype). Single-file, no build step, no dependencies.

Features (Version 1.0)
US-01 Student registration with validation and duplicate-email check
US-02 Login with error handling and protected pages
US-03 Logout
US-04 / US-05 View and update profile
US-06 Student dashboard
US-07 / US-08 Submit and view journal entries
US-09 Mood questionnaire
US-10 Mental health support resources
Demo counselor and admin dashboards (sample data)
Run it

Open index.html in a browser, or host it free with GitHub Pages (Settings → Pages → Deploy from branch → main / root).
